# ฐานข้อมูลเว็บฝึกอ่านภาษาไทย ป.1 (Supabase)

โฟลเดอร์นี้เก็บสคริปต์ SQL สำหรับสร้างฐานข้อมูลของเกม ใช้กับ Supabase (PostgreSQL)

## ลำดับการรัน

รันใน Supabase: SQL Editor → New query → วางโค้ด → Run ตามลำดับเลขนี้

1. `01_schema.sql` สร้างตาราง ฟังก์ชัน กฎความปลอดภัย (RLS) และข้อมูลด่านทั้ง 12 ด่าน
2. `02_consonants.sql` เนื้อหาพยัญชนะ
3. `03_content_all.sql` เนื้อหาสระ วรรณยุกต์ ตัวสะกด คำ การประสมคำ และประโยค
4. `04_generate_questions.sql` สร้างคำถามของทุกด่าน

## ข้อควรระวัง

- รันตอนสร้างโปรเจค Supabase ใหม่ที่ฐานข้อมูลว่างเท่านั้น ถ้ารันซ้ำในโปรเจคที่มีตารางอยู่แล้วจะขึ้น error
- ห้ามนำ Secret key (service_role) หรือรหัสผ่านใด ๆ มาใส่ใน repo นี้ เพราะ repo เป็น Public

## การทำงานของระบบ

- ครูล็อกอินด้วยบัญชี Supabase Auth และเด็กแต่ละคนคือแถวในตาราง `profiles`
- ครูเห็นและแก้ได้เฉพาะเด็กของตัวเอง (RLS)
- ด่านถัดไปจะปลดล็อกเมื่อเด็กผ่านด่านก่อนหน้า (`status = 'passed'`) ตรวจด้วยฟังก์ชัน `is_level_unlocked`

## ค่าที่หน้าเว็บต้องใช้

ได้จาก Supabase → Project Settings → API Keys
- Project URL
- Publishable key (ใส่ในหน้าเว็บได้)
