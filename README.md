คำสั่ง	ใช้ทำอะไร
git status	ตรวจสอบสถานะไฟล์
git branch	ดู Branch ในเครื่อง
git branch -a	ดู Branch ทั้งหมด ทั้งในเครื่องและ Remote
git branch --show-current	ดูชื่อ Branch ปัจจุบัน
git remote -v	ตรวจสอบ URL ของ GitHub
git log --oneline	ดูประวัติ Commit
git fetch origin	ดึงข้อมูล Branch ล่าสุดจาก GitHub โดยยังไม่รวมโค้ด
git pull	ดึงและรวมการเปลี่ยนแปลงจาก Remote
git clone URL	ดาวน์โหลด Repository มาไว้ในเครื่อง
